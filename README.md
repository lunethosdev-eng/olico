# Pokke (repo: olico)

App de música propia. v0.1

- Home: catálogo Ukiyo + tendencias (plays)
- Search / Library / Settings / Account / Admin
- Player + Lyrics (esqueleto; BitChord player en v0.2)
- Ukiyo ON, YouTube OFF por defecto
- Harvest silencioso cuando YT está ON
- Music API: ver `PokkeConfig.MUSIC_API_BASE`

## Build
GitHub Actions → artifact APK  
o `./gradlew :app:assembleDebug`
